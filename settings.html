Future Spring Boot + MySQL Integration Blueprint

Architecture Guide

StudyMate's frontend is architected using a decoupled Repository Service Layer in js/storage.js. Connecting a production Java Spring Boot 3.x + MySQL 8.0 backend requires zero modifications to UI HTML templates. Simply configure the storage engine to dispatch fetch() requests to the REST controllers outlined below.

Module HTTP Method Spring Boot Endpoint JPA Entity / MySQL Table
Auth POST /api/v1/auth/login, /register User (id, email, password_hash, role)
Notes GET/POST/PUT/DELETE /api/v1/notes Note (id, title, content, subject, is_pinned)
Tasks GET/POST/PUT/DELETE /api/v1/tasks Task (id, title, priority, due_date, completed)
Planner GET/POST/PUT/DELETE /api/v1/schedules Schedule (id, day, start_time, end_time, activity)
Materials GET/POST/DELETE /api/v1/materials Material (id, title, url, type, category)
Goals GET/POST/PUT/DELETE /api/v1/goals Goal (id, title, progress, target_date)
Quizzes GET / POST /api/v1/quizzes/results QuizResult (id, quiz_subject, score, total)
GPA GET / POST /api/v1/gpa/semesters Semester (id, semester_name, sgpa, credits)
