Got Questions?

Frequently Asked Questions

Quick answers to common questions about StudyMate.

Is StudyMate free to use?
Yes! StudyMate is completely free and student-focused. All core features including notes, tasks, study planner, focus timer, revision quizzes, and GPA calculators are available with zero paywalls.
Will my notes and tasks disappear if I refresh or close my browser?
No. StudyMate uses resilient LocalStorage persistence. Everything you create—from notes and tasks to timer logs and semester grades—is safely stored on your device. You can also export a full JSON backup from Settings anytime!
Can StudyMate be connected to a Java Spring Boot + MySQL backend?
Yes! StudyMate's JavaScript architecture uses clean service repository layers that mirror standard RESTful endpoints (`/api/v1/notes`, `/api/v1/tasks`, `/api/v1/schedules`). You can connect a Spring Boot REST API and MySQL database seamlessly without rewriting frontend logic.
Does StudyMate work on mobile devices and tablets?
Absolutely. StudyMate is crafted with responsive CSS Grid and Flexbox, complete with a collapsible mobile drawer navigation, responsive tables, and touch-friendly controls.
